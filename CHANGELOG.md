# Changelog

All notable changes to the **Ultimate Git (IntelliJ Style)** extension will be documented in this file.

## [0.0.1] - 2026-01-29

### Added
- **Unified Branches View**: A grouped view of Local and Remote branches across all workspace repositories.
- **Batch Operations**: Support for Checkout, Fetch, Pull, Push, Merge, and Rebase across multiple repositories.
- **Ahead/Behind Indicators**: Visual counters (↑/↓) showing the number of commits to push or pull.
- **Branch Search**: Quick filtering of branches by name in the Unified view.
- **Repository Filtering**: Ability to select which repositories to include in the unified branch list.
- **History for Selection**: Command to show the Git log for a specific line range.
- **Advanced Comparison**: Compare current files with branches or specific revisions.
- **IntelliJ Inspired UI**: TreeViews and context menus designed for a familiar multi-repo workflow.
