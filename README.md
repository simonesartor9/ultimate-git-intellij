# Ultimate Git (IntelliJ Style)

A powerful VS Code extension that brings the advanced multi-repository Git management experience of IntelliJ IDEA/Android Studio to VS Code.

## Features

### 💻 Unified Branches View
Manage branches from all your repositories in a single, organized view.
- **Categorized View**: Locally and Remote branches are grouped separately.
- **Aggregated Status**: See exactly how many commits you are **Ahead (↑)** or **Behind (↓)** across all repositories at a glance.
- **Repository List**: See which repositories contain each branch directly in the tree.
- **Multi-Repo Operations**: Perform Git actions on all repositories containing a specific branch simultaneously.

### 🚀 Batch Operations
- **Unified Checkout**: Switch branches across all active repositories.
- **Global Fetch & Push**: Update all your repositories with a single click.
- **Massive Merge & Rebase**: Merge or rebase a branch into your current state across the entire workspace.
- **New Branch Creation**: Create a new feature branch across multiple repositories at once.

### 🔍 Search & Filter
- **Branch Search**: Quickly find the branch you need with the built-in search bar.
- **Repository Filtering**: Focus only on specific repositories by filtering them out of the unified view.

### 📉 Advanced History & Comparison
- **History for Selection**: View Git history for a specific range of lines in a file.
- **Compare with Branch/Revision**: Easily compare your current file with any branch or specific commit hash.

## Usage

1. Open the **Git Ultimate** container in the Activity Bar.
2. Use the **Repositories** view to see the status of each individual repo.
3. Use the **Unified Branches** view to perform workspace-wide operations.
4. Click the **Search** icon (🔍) in the Unified Branches header to filter branches by name.
5. Click the **Fetch All** icon (☁️) to update all filtered repositories at once.

## Requirements

- **Git**: Ensure Git is installed and available in your system PATH.
- **Workspace**: Works best when opening a folder or workspace containing one or more Git repositories.

## Extension Settings

This extension currently uses the default Git configuration.
